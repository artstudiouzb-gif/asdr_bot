# Установка на хостинг

Проверено на тарифе с PHP 8.5, LiteSpeed, MySQL и cron (hPanel Hostinger).
Займёт около получаса, SSH не нужен — всё через файловый менеджер и панель хостинга.

## 1. База данных

hPanel → **Databases → MySQL Databases** → создайте базу и пользователя.
Запишите: имя базы, имя пользователя, пароль, хост (обычно `localhost`).

## 2. Загрузка файлов

Есть три способа — выберите любой, дальше всё одинаково.

> **Если панель живёт на субдомене** (например `bot.asdr.uz`), его каталог —
> это корень сайта. Всё содержимое устанавливаемой папки кладётся прямо туда,
> и панель открывается по адресу `https://bot.asdr.uz/`, а установка —
> `https://bot.asdr.uz/install.php`.

### Способ 1. Git-деплой из ветки `deploy` (рекомендуемый)

В ветке `deploy` репозитория лежит готовое к работе дерево: код, `vendor/` и
загрузчики. Ничего собирать не нужно.

hPanel → **Advanced → Git** → Create new repository:

| Поле | Значение |
|---|---|
| Repository address | `https://github.com/artstudiouzb-gif/asdr_bot.git` |
| Branch | `deploy` |
| Directory | каталог сайта: `public_html/bot` для адреса `ДОМЕН/bot`, либо каталог субдомена (`domains/asdr.uz/public_html/bot`) для `bot.asdr.uz` |

После «Deploy» панель будет доступна по адресу `https://ВАШ_ДОМЕН/bot/`
(или `https://bot.ВАШ_ДОМЕН/`, если это субдомен), установка — `…/install.php`.
Обновление — кнопкой **Deploy** в том же разделе, когда выйдет новая версия.

### Способ 2. Архив (без git)

Самое простое: распакуйте архив **целиком** в каталог сайта (или субдомена) —
в корне архива лежит свой `index.php`, поэтому адрес каталога сразу открывает панель:

* `https://bot.ВАШ_ДОМЕН/install.php` — установка,
* `https://bot.ВАШ_ДОМЕН/` — панель.

Если хочется без лишних папок, положите в каталог сайта содержимое папки
**`reposter`** из архива — адреса те же.

Код при этом лежит внутри `public_html`, но каталоги `app`, `bin`, `db`, `vendor`,
`storage` и файл `.env` закрыты файлами `.htaccess` — по HTTP они не отдаются.

### Способ 3. Код вне public_html (самый строгий)

```
domains/ВАШ_ДОМЕН/
├── reposter/          ← папка reposter из архива, недоступна из интернета
└── public_html/
    └── panel/         ← папка panel из архива
```

Панель: `https://ВАШ_ДОМЕН/panel/`. Загрузчик сам находит каталог с кодом —
редактировать пути не нужно. Если каталог лежит в необычном месте, создайте рядом
с `index.php` файл `reposter-path.php`:

```php
<?php return '/home/ПОЛЬЗОВАТЕЛЬ/domains/ВАШ_ДОМЕН/reposter';
```

## 3. Файл .env

В корне установленной папки (там, где лежат `app/` и `vendor/`) переименуйте
`.env.example` в `.env` и заполните:

```env
APP_URL=https://ВАШ_ДОМЕН/panel
APP_KEY=              # 64 случайных символа, см. ниже
TIMEZONE=Asia/Tashkent

DB_HOST=localhost
DB_NAME=имя_базы
DB_USER=пользователь
DB_PASS=пароль

TG_API_ID=            # my.telegram.org → API development tools
TG_API_HASH=

CRON_KEY=             # длинная случайная строка
INSTALL_KEY=          # длинная случайная строка, после установки можно стереть
```

`APP_KEY`, `CRON_KEY`, `INSTALL_KEY` — любые длинные случайные строки (64 символа).
Проще всего взять их из любого генератора паролей.

Права на файл `.env` поставьте **600** (файловый менеджер → Permissions).

## 4. Установка схемы и администратора

Откройте `https://ВАШ_ДОМЕН/bot/install.php?key=ЗНАЧЕНИЕ_INSTALL_KEY`
(или `/panel/install.php?key=…` при третьем способе установки):

1. «Применить миграции» — создаст 16 таблиц.
2. Создайте администратора (логин и пароль от 10 символов).
3. **Удалите `install.php`** из установленной папки — он больше не нужен.
   При git-деплое вместо удаления сотрите значение `INSTALL_KEY` в `.env`:
   без ключа страница отдаёт 403.

## 5. Cron

hPanel → **Advanced → Cron Jobs** → добавьте задание с интервалом «каждую минуту»:

```
/usr/bin/php /home/ПОЛЬЗОВАТЕЛЬ/domains/ВАШ_ДОМЕН/public_html/bot/bin/cron.php
```

Если интервал в минуту недоступен, поставьте 5 минут — посты будут выходить с такой задержкой.
Если cron на хостинге умеет только открывать адреса, используйте вместо этого:

```
https://ВАШ_ДОМЕН/panel/cron.php?key=ЗНАЧЕНИЕ_CRON_KEY
```

## 6. Подключение Telegram

1. Войдите в панель: `https://ВАШ_ДОМЕН/panel/`.
2. Раздел **Аккаунты** → укажите название и номер телефона (отдельный, не личный).
3. Через минуту (после запуска cron) статус сменится на «ждёт код» — код придёт в Telegram.
4. Введите код, при включённой двухфакторной защите — пароль.
5. Статус «подключён» означает, что аккаунт готов читать каналы.

## 7. Источники, назначения, маршруты

1. **Источники** — добавьте каналы, откуда берём новости (`@shmirziyoyev` или ссылка).
   Кнопка «Проверить» ставит задание воркеру; результат — на странице «Аккаунты».
2. **Назначения** — ваши каналы. Аккаунт должен быть их администратором,
   а в настройках канала **выключено «Подписывать сообщения»** — иначе Telegram
   подпишет пост именем администратора.
3. **Маршруты** — свяжите источники с назначениями, задайте задержку.

## 8. Проверка работы

* Дашборд показывает время последнего запуска воркера. Если больше 5 минут — cron не работает.
* Страница «Аккаунты» показывает результат последних заданий.
* Журналы: `storage/logs/` (файлы `app-*.log`, `madeline.log`, `cron.log`).

## 9. Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Белая страница | `storage/logs/app-*.log` — там текст ошибки |
| «Воркер не отвечает» | проверьте задание cron и путь к PHP; запустите вручную адрес `cron.php?key=…` |
| Не приходит код | номер введён в международном формате, аккаунт не заблокирован Telegram |
| «Канал приватный» | аккаунт должен быть подписан на этот канал |
| Ошибка базы | сверьте DB_* в `.env`; хост обычно `localhost` |
| «Не найден код репостера» | страница покажет, где именно искала; создайте `reposter-path.php` с нужным путём |
| Нужно сбросить пароль администратора | удалите строку из таблицы `admins` через phpMyAdmin, верните `INSTALL_KEY` в `.env` и откройте `install.php` снова |

## 10. Безопасность после установки

* `install.php` удалён или `INSTALL_KEY` стёрт;
* `.env` с правами 600;
* служебные каталоги не отдаются по HTTP — проверьте, открыв
  `https://ВАШ_ДОМЕН/bot/.env` и `https://ВАШ_ДОМЕН/bot/app/bootstrap.php`
  (должна быть ошибка 403);
* файл сессии Telegram (`reposter/storage/telegram/`) — это полный доступ к аккаунту,
  не копируйте его и не выкладывайте.
